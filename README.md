## Full-stack веб-приложение: SaaS-платформа управления проектами

Монорепозиторий с современным, масштабируемым и SEO-дружественным веб-приложением:

- `frontend` — публичный сайт и SPA-приложение на Next.js (React), адаптивный UI.
- `backend` — REST API на NestJS (Node.js) с JWT-аутентификацией.
- `db` — PostgreSQL как основная реляционная БД.

### Общая архитектура

- Клиент (Next.js) общается с backend через REST API (`/api/v1/...`).
- Backend — модульная архитектура NestJS (модули: `auth`, `users`, `projects`, `tasks`).
- Доступ к БД через ORM (Prisma или TypeORM) с миграциями.
- Разделение на окружения: `development`, `staging`, `production` через `.env`.

### Структура монорепозитория (высокоуровневая)

- `frontend/` — клиентское приложение.
- `backend/` — серверное приложение.
- `infra/` — инфраструктура и конфигурации (docker-compose, CI/CD и т.п.) — будет добавлено на этапах деплоя.

Подробная структура папок будет описана и реализована в следующих этапах.
